# Cafe_Management
☕ Cafe Management System

A simple Cafe Management System website created using HTML, CSS, and JavaScript.

🚀 Features

- Home page
- Cafe menu
- Add items to cart
- Remove items from cart
- Automatic total calculation
- Place order functionality
- Responsive design
- Simple and beginner-friendly UI

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

📂 Project Structure

Cafe-Management-System/
│
├── index.html
├── style.css
├── script.js
└── README.md

▶️ How to Run

1. Download or clone the repository.
2. Open the project in VS Code.
3. Open "index.html".
4. Right-click and select Open with Live Server.
5. The Cafe Management webpage will open in your browser.

📌 Project Purpose

This project was created to practice frontend web development using HTML, CSS, and JavaScript.
